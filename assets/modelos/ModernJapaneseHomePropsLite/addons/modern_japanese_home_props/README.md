# Modern Japanese Home Props Lite

Version 0.4.2 · 16 original assets · MIT License

## Install

Copy `assets/modern-japanese-props/` into an existing Godot 4.6 project.
Wait for import, then drag `assets/modern-japanese-props/scenes/*.tscn` into your scene.
This is an asset addon. No project.godot or editor plugin activation is required.

## Contents

- `models/`: GLB models with embedded PBR textures, in meters.
- `scenes/`: placement scenes with static collision shapes.
- `demo/`: open DemoRoom.tscn or Showcase.tscn and press F6.
- Drag to orbit, scroll to zoom, R to reset, Tab to switch demos.
- The supplied demo scripts, scenes, models, textures and documentation are all MIT licensed.
- Preserve the single `LICENSE` file when distributing copies, as required by MIT.

Keep the `res://assets/modern-japanese-props/` path intact. Showcase objects are scaled for display; placement scenes use real size. Normal maps use OpenGL +Y. Collision shapes are approximate. Demo architecture is presentation geometry and is not counted as another asset.
